# wwol Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Python-stdlib-only web app for a Raspberry Pi that shows configured PCs' online status and wakes them with a Wake-on-LAN magic packet.

**Architecture:** Four small modules in a `wwol` package — `config` (load/validate JSON), `wol` (build/send magic packet), `status` (concurrent ping), `server` (`ThreadingHTTPServer` serving one static HTML page plus a JSON API). Deployed to `/opt/wwol` by `install.sh` and run by a systemd unit as an unprivileged `wwol` user.

**Tech Stack:** Python 3.7+ standard library, `unittest`, plain HTML/CSS/JS, systemd, POSIX `sh`.

**Spec:** `docs/superpowers/specs/2026-10-11-wwol-design.md`

## Review Focus

1. **Config saved by Windows Notepad with a UTF-8 BOM** → must load normally, not fail with "not valid JSON". (Task 1: `test_loads_file_with_utf8_bom`)
2. **Wrong-typed config values** (`"port": "8080"`, `"port": true`, top-level JSON list, device given as a string) → clear `ConfigError` naming the field, never a traceback. (Task 1: `test_invalid_configs`)

5. **Device with no `ip`** → status `unknown` and is never passed to ping. (Task 4: `test_devices_reports_status`)

```python
"""Load and validate the wwol config file."""
import ipaddress
import json
import re
from dataclasses import dataclass
from typing import List, Optional

DEFAULT_HOST = "0.0.0.0"
DEFAULT_PORT = 8080
DEFAULT_WOL_PORT = 9

_MAC_SEPARATORS = re.compile(r"[:.\-]")
_MAC_DIGITS = re.compile(r"[0-9A-Fa-f]{12}")


class ConfigError(Exception):
    """The config file is missing or invalid. The message is shown to the user."""


@dataclass(frozen=True)
class Device:
    name: str
    mac: str
    broadcast: str
    wol_port: int = DEFAULT_WOL_PORT
    ip: Optional[str] = None


@dataclass(frozen=True)
class Config:
    host: str
    port: int
    devices: List[Device]


def normalize_mac(value):
    """Return value as 'AA:BB:CC:DD:EE:FF'. Raises ValueError if it isn't a MAC."""
    if not isinstance(value, str):
        raise ValueError("MAC address must be a string")
    digits = _MAC_SEPARATORS.sub("", value.strip())
    if not _MAC_DIGITS.fullmatch(digits):
        raise ValueError("{!r} is not a valid MAC address".format(value))
    digits = digits.upper()
    return ":".join(digits[i:i + 2] for i in range(0, 12, 2))


def load_config(path):
    """Read and validate the config file at path."""
    try:
        # utf-8-sig also accepts files saved with a BOM (e.g. by Windows Notepad).
        with open(path, encoding="utf-8-sig") as f:
            data = json.load(f)
    except FileNotFoundError:
        raise ConfigError("Config file not found: {}".format(path)) from None
    except json.JSONDecodeError as e:
        raise ConfigError("{} is not valid JSON: {}".format(path, e)) from None
    except (OSError, UnicodeDecodeError) as e:
        raise ConfigError("Cannot read {}: {}".format(path, e)) from None
    return parse_config(data)


def parse_config(data):
    """Validate already-parsed JSON data and build a Config."""
    if not isinstance(data, dict):
        raise ConfigError("Config must be a JSON object")
    host = data.get("host", DEFAULT_HOST)
    if not isinstance(host, str) or not host.strip():
        raise ConfigError("host: must be a non-empty string like \"0.0.0.0\"")
    port = _port(data.get("port", DEFAULT_PORT), "port")
    if "broadcast" not in data:
        raise ConfigError("broadcast: required, e.g. \"192.168.1.255\"")
    default_broadcast = _ipv4(data["broadcast"], "broadcast")
    devices = data.get("devices")
    if not isinstance(devices, list) or not devices:
        raise ConfigError("devices: must be a non-empty list")
    return Config(
        host=host.strip(),
        port=port,
        devices=[_device(raw, i, default_broadcast) for i, raw in enumerate(devices)],
    )


def _device(raw, index, default_broadcast):
    where = "devices[{}]".format(index)
    if not isinstance(raw, dict):
        raise ConfigError("{}: must be an object with name and mac".format(where))
    name = raw.get("name")
    if not isinstance(name, str) or not name.strip():
        raise ConfigError("{}.name: must be a non-empty string".format(where))
    try:
        mac = normalize_mac(raw.get("mac"))
    except ValueError as e:
        raise ConfigError("{}.mac: {}".format(where, e)) from None
    ip = raw.get("ip")
    if ip is not None:
        ip = _ipv4(ip, where + ".ip")
    broadcast = default_broadcast
    if "broadcast" in raw:
        broadcast = _ipv4(raw["broadcast"], where + ".broadcast")
    wol_port = _port(raw.get("wol_port", DEFAULT_WOL_PORT), where + ".wol_port")
    return Device(name=name.strip(), mac=mac, broadcast=broadcast,
                  wol_port=wol_port, ip=ip)


def _ipv4(value, where):
    if not isinstance(value, str):
        raise ConfigError("{}: must be a string like \"192.168.1.255\"".format(where))
    try:
        return str(ipaddress.IPv4Address(value.strip()))
    except ValueError:
        raise ConfigError(
            "{}: {!r} is not a valid IPv4 address".format(where, value)) from None


def _port(value, where):
    # bool is a subclass of int, so reject it explicitly.
    if isinstance(value, bool) or not isinstance(value, int) or not 1 <= value <= 65535:
        raise ConfigError("{}: must be a whole number from 1 to 65535".format(where))
    return value
```

```python
"""Build and send Wake-on-LAN magic packets."""
import socket


def build_magic_packet(mac):
    """6 x 0xFF followed by the 6-byte MAC repeated 16 times (102 bytes)."""
    mac_bytes = bytes.fromhex(mac.replace(":", ""))
    if len(mac_bytes) != 6:
        raise ValueError("{!r} is not a valid MAC address".format(mac))
    return b"\xff" * 6 + mac_bytes * 16


def send_magic_packet(mac, broadcast, port=9):
    """Send a magic packet for mac to the broadcast address over UDP."""
    packet = build_magic_packet(mac)
    with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as sock:
        sock.setsockopt(socket.SOL_SOCKET, socket.SO_BROADCAST, 1)
        sock.sendto(packet, (broadcast, port))
```

```python
"""Check whether hosts are online with a single ping."""
import subprocess
from concurrent.futures import ThreadPoolExecutor

MAX_WORKERS = 8


def is_online(ip, timeout=1):
    """True if ip answers one ping within timeout seconds. Never raises."""
    try:
        result = subprocess.run(
            ["ping", "-c", "1", "-W", str(timeout), ip],
            stdout=subprocess.DEVNULL,
            stderr=subprocess.DEVNULL,
            timeout=timeout + 1,
        )
    except (OSError, subprocess.TimeoutExpired):
        return False
    return result.returncode == 0


def check_all(ips, timeout=1):
    """Ping every unique ip concurrently. Returns {ip: online}."""
    unique = list(dict.fromkeys(ips))
    if not unique:
        return {}
    with ThreadPoolExecutor(max_workers=min(MAX_WORKERS, len(unique))) as pool:
        results = list(pool.map(lambda ip: is_online(ip, timeout), unique))
    return dict(zip(unique, results))
```

```python
"""HTTP server: serves the web page and a small JSON API.

Run with: python3 -m wwol.server [--config PATH]
"""
import argparse
import json
import os
import re
import sys
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from urllib.parse import urlsplit

from wwol import status, wol
from wwol.config import ConfigError, load_config

PROJECT_ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
DEFAULT_CONFIG = os.path.join(PROJECT_ROOT, "config.json")
DEFAULT_STATIC = os.path.join(PROJECT_ROOT, "static")
WAKE_PREFIX = "/api/wake/"
_DEVICE_ID = re.compile(r"[0-9]+")


def make_handler(config, static_dir):
    class Handler(BaseHTTPRequestHandler):
        def do_GET(self):
            self._dispatch("GET")

        def do_POST(self):
            self._dispatch("POST")

        def _dispatch(self, method):
            path = urlsplit(self.path).path
            if path.startswith(WAKE_PREFIX):
                allowed = "POST"
                action = lambda: self._wake(path[len(WAKE_PREFIX):])
            elif path == "/api/devices":
                allowed, action = "GET", self._devices
            elif path == "/":
                allowed, action = "GET", self._index
            elif path.startswith("/api/"):
                return self._send_json(404, {"ok": False, "error": "Not found"})
            else:
                return self._send_text(404, "Not found")
            if method != allowed:
                headers = {"Allow": allowed}
                if path.startswith("/api/"):
                    return self._send_json(
                        405, {"ok": False, "error": "Method not allowed"}, headers)
                return self._send_text(405, "Method not allowed", headers)
            action()

        def _index(self):
            try:
                with open(os.path.join(static_dir, "index.html"), "rb") as f:
                    body = f.read()
            except OSError as e:
                self.log_error("Cannot read index.html: %s", e)
                return self._send_text(500, "index.html is missing")
            self._send(200, "text/html; charset=utf-8", body)

        def _devices(self):
            online = status.check_all([d.ip for d in config.devices if d.ip])
            devices = []
            for i, d in enumerate(config.devices):
                if d.ip is None:
                    state = "unknown"
                else:
                    state = "online" if online.get(d.ip) else "offline"
                devices.append({"id": i, "name": d.name, "mac": d.mac,
                                "ip": d.ip, "status": state})
            self._send_json(200, devices)

        def _wake(self, raw_id):
            if not _DEVICE_ID.fullmatch(raw_id) or int(raw_id) >= len(config.devices):
                return self._send_json(404, {"ok": False, "error": "Unknown device"})
            device = config.devices[int(raw_id)]
            try:
                wol.send_magic_packet(device.mac, device.broadcast, device.wol_port)
            except OSError as e:
                self.log_error("Failed to wake %s (%s): %s", device.name, device.mac, e)
                return self._send_json(500, {"ok": False, "error": str(e)})
            self.log_message("Sent magic packet to %s (%s) via %s:%d",
                             device.name, device.mac, device.broadcast, device.wol_port)
            self._send_json(200, {"ok": True})

        def _send_json(self, code, obj, headers=None):
            body = json.dumps(obj).encode("utf-8")
            self._send(code, "application/json", body, headers)

        def _send_text(self, code, text, headers=None):
            self._send(code, "text/plain; charset=utf-8", text.encode("utf-8"), headers)

        def _send(self, code, content_type, body, headers=None):
            self.send_response(code)
            self.send_header("Content-Type", content_type)
            self.send_header("Content-Length", str(len(body)))
            self.send_header("Cache-Control", "no-store")
            for name, value in (headers or {}).items():
                self.send_header(name, value)
            self.end_headers()
            self.wfile.write(body)

    return Handler


def create_server(config, static_dir=DEFAULT_STATIC):
    return ThreadingHTTPServer((config.host, config.port),
                               make_handler(config, static_dir))


def main(argv=None):
    parser = argparse.ArgumentParser(
        prog="wwol", description="Wake-on-LAN web app for Raspberry Pi.")
    parser.add_argument("--config", default=DEFAULT_CONFIG,
                        help="path to config.json (default: %(default)s)")
    args = parser.parse_args(argv)
    try:
        config = load_config(args.config)
    except ConfigError as e:
        print("Config error: {}".format(e), file=sys.stderr)
        return 1
    try:
        server = create_server(config)
    except OSError as e:
        print("Cannot listen on {}:{}: {}".format(config.host, config.port, e),
              file=sys.stderr)
        return 1
    print("Listening on http://{}:{}".format(config.host, config.port), flush=True)
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        pass
    finally:
        server.server_close()
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

```sh
# Install or upgrade wwol. Run from the project directory as root:
#   sudo sh install.sh
set -eu

APP_DIR=/opt/wwol
SERVICE_FILE=/etc/systemd/system/wwol.service
SRC_DIR=$(cd "$(dirname "$0")" && pwd)

    echo "Please run as root: sudo sh install.sh" >&2
    exit 1

command -v python3 >/dev/null 2>&1 || missing="$missing python3"

if [ -n "$missing" ]; then
    echo "Missing packages:$missing" >&2
    echo "Install them with: apt update && apt install -y$missing" >&2

    exit 1

rm -rf "$APP_DIR/wwol" "$APP_DIR/static"

    new_config=1

chown -R root:wwol "$APP_DIR"
chmod -R u=rwX,g=rX,o= "$APP_DIR"

install -m 644 "$SRC_DIR/wwol.service" "$SERVICE_FILE"
systemctl daemon-reload

systemctl restart wwol
```

````markdown
# wwol — Wake-on-LAN from a Raspberry Pi

wwol is a tiny web app for a Raspberry Pi. Open it in any browser on your home
network, see which PCs are on, and press **Wake Up** to turn one on with a
Wake-on-LAN "magic packet". It uses only Python's standard library — no pip, no
Node — so it runs comfortably on a Pi Zero.

Built for:
- **Raspberry Pi Zero** running **DietPi**, networked with a USB-Ethernet adapter
- **Raspberry Pi 3B** running **Raspberry Pi OS Lite**

> **Security:** wwol has no login. Anyone on your network can wake your PCs.
> Keep it on your home network and never port-forward it to the internet.

## 1. Prepare the PC you want to wake

1. **BIOS/UEFI:** enable Wake-on-LAN. The setting may be called "Wake on LAN",
   "Power On By PCI-E", or "Resume by LAN". If there is an "ErP Ready" or
   "Deep Sleep" option, disable it — it cuts power to the network card.
2. **Windows network adapter:** Device Manager → Network adapters → your
   Ethernet adapter → Properties:
   - **Power Management:** tick "Allow this device to wake the computer" and
     "Only allow a magic packet to wake the computer".
   - **Advanced:** set "Wake on Magic Packet" to **Enabled** (and "Shutdown
     Wake-On-Lan" if it is listed).
3. **Turn off Fast Startup:** Control Panel → Power Options → Choose what the
   power buttons do → Change settings that are currently unavailable → untick
   "Turn on fast startup".
4. **Use wired Ethernet.** Wake-on-LAN over Wi-Fi almost never works.
5. **Find the MAC address:** run `ipconfig /all` and copy the "Physical
   Address" of the Ethernet adapter, e.g. `AA-BB-CC-DD-EE-FF`.
6. **For the online/offline indicator (optional):**
   - Give the PC a fixed IP with a DHCP reservation in your router.
   - Let Windows answer ping. In an administrator PowerShell:
     ```powershell
     Get-NetFirewallRule -DisplayName "*Echo Request*ICMPv4-In*" | Enable-NetFirewallRule
     ```

## 2. Set up the Pi

### Raspberry Pi Zero with DietPi

1. Download the DietPi image for **Raspberry Pi 1 / Zero (ARMv6)** from
   <https://dietpi.com> and flash it to the SD card with Raspberry Pi Imager
   ("Use custom") or balenaEtcher.
2. *(Optional, before first boot)* Open `dietpi.txt` on the SD card's boot
   partition to make sure Ethernet is used and, if you like, set a static IP.
   Check the comments in the file for the current option names; at the time of
   writing they are:
   ```ini
   AUTO_SETUP_NET_ETHERNET_ENABLED=1
   AUTO_SETUP_NET_WIFI_ENABLED=0
   AUTO_SETUP_NET_USESTATIC=1
   AUTO_SETUP_NET_STATIC_IP=192.168.1.20
   AUTO_SETUP_NET_STATIC_MASK=255.255.255.0
   AUTO_SETUP_NET_STATIC_GATEWAY=192.168.1.1
   AUTO_SETUP_NET_STATIC_DNS=192.168.1.1
   ```
   Skip the static-IP lines if you'd rather reserve the Pi's IP in your router.
3. Plug the USB-Ethernet adapter into the micro-USB port marked **USB** (not
   **PWR IN**) using an OTG adapter, connect the network cable, then power on.
   The first boot takes several minutes while DietPi updates itself.
4. Find the Pi's IP in your router, then SSH in: `ssh root@<pi-ip>` (default
   password `dietpi`). Finish DietPi's first-run setup and change the passwords
   when asked.
5. Check the adapter is up:
   ```sh
   ip -4 addr show eth0
   ```
   You should see an `inet` line. If `eth0` doesn't exist, run `ip link` to see
   the adapter's name (some appear as `enx…`), and use `dietpi-config` →
   Network Options: Adapters to enable Ethernet.
6. Install the packages wwol needs:
   ```sh
   apt update
   apt install -y python3 iputils-ping git
   ```

On DietPi you are logged in as `root`, so leave `sudo` off the commands in the
rest of this guide.

### Raspberry Pi 3B with Raspberry Pi OS Lite

1. Flash **Raspberry Pi OS Lite** with Raspberry Pi Imager. In Imager's
   settings, set a hostname and user and enable SSH.
2. Connect Ethernet (recommended), boot, and SSH in.
3. Install the packages (usually already present):
   ```sh
   sudo apt update
   sudo apt install -y python3 iputils-ping git
   ```
4. Reserve the Pi's IP in your router so the web address doesn't change.

## 3. Install wwol

Get the code onto the Pi, either with git:

```sh
git clone <your-repo-url> wwol
cd wwol
```

or by copying it from your PC (run this on the PC):

```powershell
scp -r C:\GitProjects\wwol root@<pi-ip>:/root/wwol
```

Then, in the `wwol` directory on the Pi:

```sh
sudo sh install.sh
```

The installer:
- checks that `python3` (3.7+) and `ping` are installed
- creates a `wwol` system user
- copies the app to `/opt/wwol`
- creates `/opt/wwol/config.json` from the example (an existing config is never overwritten)
- installs and starts the `wwol` systemd service, which starts on boot

## 4. Configure your PCs

1. Find your network's broadcast address on the Pi:
   ```sh
   ip -4 addr show eth0
   ```
   In `inet 192.168.1.20/24 brd 192.168.1.255`, the broadcast address is the
   value after `brd`: `192.168.1.255`.
2. Edit the config:
   ```sh
   sudo nano /opt/wwol/config.json
   ```
   ```json
   {
     "host": "0.0.0.0",
     "port": 8080,
     "broadcast": "192.168.1.255",
     "devices": [
       { "name": "Gaming PC", "mac": "AA:BB:CC:DD:EE:FF", "ip": "192.168.1.50" },
       { "name": "Media PC", "mac": "11-22-33-44-55-66" }
     ]
   }
   ```

   | Field | Required | Default | Meaning |
   |---|---|---|---|
   | `host` | no | `0.0.0.0` | Network interface the web page listens on (`0.0.0.0` = all) |
   | `port` | no | `8080` | Web page port |
   | `broadcast` | yes | — | Broadcast address used for all PCs |
   | `devices[].name` | yes | — | Name shown on the page |
   | `devices[].mac` | yes | — | PC's MAC address; `AA:BB:…`, `AA-BB-…` and `AABB…` all work |
   | `devices[].ip` | no | — | PC's IP, used for the online/offline indicator |
   | `devices[].broadcast` | no | top-level `broadcast` | Override for a PC on another subnet |
   | `devices[].wol_port` | no | `9` | UDP port for the magic packet (some PCs use `7`) |

3. Restart and check it started:
   ```sh
   sudo systemctl restart wwol
   systemctl status wwol
   ```

## 5. Use it

Open `http://<pi-ip>:8080` on your phone or PC.

| Status | Meaning |
|---|---|
| green **online** | the PC answers ping |
| red **offline** | no answer to ping |
| yellow **waking** | magic packet sent; waiting up to 2 minutes for the PC to come online |
| outlined **unknown** | no `ip` set in the config, so status can't be checked |

The page refreshes every 10 seconds.

## Troubleshooting

**The PC doesn't wake up**
- Check the logs show `Sent magic packet to …`: `journalctl -u wwol -n 20`.
- Double-check the MAC address and the `broadcast` address.
- The PC must be on wired Ethernet with Fast Startup off.
- Try waking it from sleep first. If that works but waking from shut down
  doesn't, look for "ErP" / "Deep Sleep" in the BIOS and disable it.
- Some PCs listen on port 7: set `"wol_port": 7` on that device.

**Status is always offline**
- Check the `ip` in the config is the PC's current IP.
- From the Pi, run `ping -c 1 <pc-ip>`. If that fails too, allow ping in the
  Windows firewall (see step 1.6).

**Status is always unknown**
- That device has no `ip` in the config.

**The page won't load**
- `systemctl status wwol` — is it running?
- `journalctl -u wwol -n 50` — look for `Config error: …`, which names the
  field that's wrong, or `Cannot listen on …` if another program uses the port.

**Pi Zero: the USB-Ethernet adapter isn't detected**
- Make sure it's in the **USB** port, not **PWR IN**, and that the OTG adapter
  is a data adapter.
- `lsusb` should list the adapter; `dmesg | tail -n 30` shows driver messages.
````
